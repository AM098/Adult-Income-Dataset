# Adult-Income-Dataset
Adult Income Dataset – In this project, we perform Exploratory Data Analysis (EDA) on the Adult Income Dataset using Python and the Pandas library. The main objective is to understand the dataset, clean the data, analyze different columns, and identify the factors that influence a person's income.
